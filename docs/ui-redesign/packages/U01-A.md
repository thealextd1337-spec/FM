## Minimaler Projektionsvorschlag für I00

```js
overview: {
  fixture: null | {
    dateLabel, seasonLabel, competitionLabel, roundLabel,
    home: { id, name, crestHTML, rankLabel, recent: [{ outcome, label, detail }] },
    away: { id, name, crestHTML, rankLabel, recent: [{ outcome, label, detail }] }
  },
  sponsor: null | {
    name, logoHTML,
    goals: [{ label, bonusLabel, onCourse, achieved, paid }]
  }
}
```

Texte sind lokalisierte Anzeigetexte; `outcome` ist `win|draw|loss`. `crestHTML`/`logoHTML` ausschließlich lokales vertrauenswürdiges SVG. Die drei Sponsorstatuswerte sind unabhängig `boolean|null`; null wird als unbekannt ausgegeben. Keine internen Spielerobjekte, Fähigkeiten oder Vertragszustände an den Renderer weiterreichen. Bestehende Konditionen und Angebote stehen bereits im DOM, benötigen keine duplizierte Projektion. Bestehende Ereignis-/Saisonabschnitte bleiben vollständig und benötigen ebenfalls keine Projektion.

Produzenthinweise: Begegnung wie `v62CareerViewsHTML`: `v62Fixtures(career).filter(f => !f.result && (f.homeId === managed || f.awayId === managed)).sort((a,b) => a.day-b.day)[0]`. Ergebnisfolge über erfasste `world.competitions` mit `type === 'league'`, Saison/Tag sortieren, nur abgeschlossene Partien des jeweiligen Teams, letzte fünf. `v62RecentGames` enthält auch Pokalspiele und genügt ungefiltert nicht. Heim-/Auswärtsergebnis aus Sicht des jeweiligen Teams beschriften. Sponsor über eigenes `club.sponsors.find(id === sponsorId)`, Logo `v66SponsorLogoSVG`. Zahlungsnachweis aus Ledger-ID `${sponsor.id}:bonus:${index}`, nicht aus Zielerfüllung oder Farbe. Liga: vorläufig auf Kurs nur bei bekanntem Rang >= 1 und <= Ziel; endgültig erst abgeschlossene Liga. Pokal-/Toreziel kann bereits erreicht und noch unbezahlt sein, gemäß `v66SponsorMet`. Keine Buchung oder weitere Modellmutation.
